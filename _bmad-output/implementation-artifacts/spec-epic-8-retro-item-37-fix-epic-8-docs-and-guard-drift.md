## Intent

**Problem:** Epic 8 retro findings R6-R11 left docs and one guard message out of line with the as-built: `docs/pipelines.md` says CI has no `tofu validate`; `domain.md` says a new `stage` or map key changes the A record in place; the `dns-zone.md` steps table does not list `tofu validate`; runbook R4 (state lost) builds the import keys from `tofu output dns_records`, which reads the very state being rebuilt and returns FQDNs; the deploy DNS guard `fail_msg` sends the operator to that same state output first, so a zone or delegation removed outside OpenTofu looks fine and the operator waits for caches; and `.gitignore` does not cover the `dns.tfplan` the runbook writes into the repo.

**Approach:** Fix each place in the docs, the guard message (plus its Molecule assert and the role README/deployment docs that quote it), and `.gitignore`. The guard message checks authoritative DNS first (`task cloud:dns:check -- +norec @ns1.digitalocean.com <domain> A`), then a `tofu plan` (which reads the API, not only state) if that answer is wrong, then the resolver cache. R4 takes names and IDs from `doctl compute domain records list`. Implement on `main`; do not commit until the user says so.

</frozen-after-approval>

### Process Lessons

- **P1, off-story work inside an epic (A2):** CI work that closed a deferred item landed between story commits. It had no spec and no review, and it did not update the deferred-work file or the downstream story it partly delivers. Its defects (R1-R5) are exactly the kind a story review catches.
- **P2, runbook waits (A1):** the operator skipped a safety wait once its purpose was already proven by observation. The runbook should state the observable condition the wait protects, not only the time, so the next run of the runbook (another provider label) can use it.
- Session logs were not available, so no further process lessons were derived from them.

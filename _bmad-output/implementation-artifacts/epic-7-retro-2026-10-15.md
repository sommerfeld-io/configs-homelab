### Process Lessons (Story 7.2 Session)

- **Expected outputs in docs were written before anyone looked at the live app.** The Checks said `https://<domain>/` prints `200`; the deploy showed `302` to `/login` (fixed in `e792dad`, recorded in the 7.2 Implementation Notes). Lesson: take expected outputs from a live probe or the app's behavior, not from the proxy's design.
- **A fix in triage did not reach the docs that describe it.** The guard became an equality check during the 7.2 review patch round, and the five sentences describing it stayed (finding 1). Lesson: when a review patch changes behavior, grep the docs for the old wording in the same patch.
- **The droplet could not be inspected before the deploy.** A read-only SSH query was blocked by the session's permission classifier, so the metadata path and the droplet's resolver were first exercised by the operator's deploy. It worked first time, but only by luck of the docs being right.
- **The pre-commit hook stashes unstaged files for minutes.** An operator edit during the `lint-repo` run aborted the first 7.2 commit (nothing lost). Lesson: commit while nobody edits the tree.
- **No per-story review loopbacks:** both Spec Change Logs are empty. 7.2's spec ran past the 1,600-token guideline (about 2,000) and no review finding traced back to the spec.
